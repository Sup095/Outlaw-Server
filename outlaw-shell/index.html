SYSTEM CORE

VRAM: probing… COLD · standalone
What is the System Core?

The System Core is your machine's command center — live status, the Core assistant, diagnostics, and one-tap actions (talk to Cr1tt3r, report a problem, take a screenshot, update). The rings show live CPU, RAM and VRAM use. The badge shows the current VRAM-saver tier (change it in Settings → AI / VRAM).

Cold mode (default) uses built-in dialogue and sends zero AI traffic — fully offline and free. Go Live connects to your AI engine so the Core can answer questions and run safe actions for you (open an app, run a diagnostic, search files). It uses whichever engine you've set in Settings → AI: the built-in base AI (on by default, runs on almost any PC, nothing to install), a model you pull through Ollama, or a model you load in LM Studio. All of it runs locally — nothing leaves your machine.

Use the controls here to run a system diagnostic, watch temperatures, toggle performance mode, and talk to the Core. Nothing leaves your machine.

Task Manager

What is this?

A live view of everything running. The bars show CPU, memory and GPU / VRAM use. Click a row to select a process, then End task (asks it to close nicely) or End process tree (force-closes it and everything it started). Click a column heading to sort. The list refreshes every couple of seconds while you're on this screen. Some processes belong to the administrator and show needs admin when you try to end them — that's expected.

Secure Terminal

How does the terminal work?

A normal shell — type a command and press Enter; output appears above. It runs in your home folder as you. Destructive commands (like rm -rf, dd, mkfs) are intercepted and need you to type CONFIRM first, so you can't wipe the machine by accident. Use sudo for admin tasks; pacman for packages (or just use the Apps page).

Session graphics profile

What is this?

Installs the gaming/desktop graphics stack for your GPU — Vulkan, Mesa and the 32-bit libraries Steam & Proton need, plus GameMode and MangoHUD. It's userspace only: it never changes kernel drivers, the boot loader or your display mode, so it can't stop the machine booting. Use lean for dev/planning. Applied after boot via the package manager, and fully revertible. (NVIDIA: this installs the userspace libraries only — the NVIDIA kernel driver touches the boot path and isn't installed automatically.)

Tested this build? One click opens a pre-filled report on GitHub — just review and hit Submit. Reports are advisory and help the maintainer decide which version to mark stable. (No account info is sent; a short anonymous machine hash is included so duplicates can be merged.)

Boot & Recovery

Hotswap sets the next boot to another installed OS (or opens the boot menu). The installer can set up or remove Outlaw OS — your other OS and data stay untouched unless you explicitly choose to wipe.

Report a problem

If something failed, crashed, or bounced you to the session picker, collect the log and report it. It gathers errors + warnings from the desktop, the dev session, Xorg and the system journal — deduplicated, no repeats. Copy the log, click Open GitHub issues, and paste it into a new issue. When you’re done reporting, Clear it so already-sent errors don’t pile up with new ones.
