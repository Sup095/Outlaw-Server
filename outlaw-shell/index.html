Everything this machine runs in the background — your game server, SSH, the firewall, the control panel itself. Running means it is up right now; enabled means it comes back on its own after a reboot. Those are separate on purpose: you can stop something temporarily without it returning at boot, or set it to start at boot without starting it this second. What is this?

The system journal — what the machine has been saying about itself. When something breaks, the reason is almost always here. Type a service name (like sshd or outlaw-serverd) to see only its messages, or leave it blank for everything. Newest lines are at the bottom.

Firewall

checking…
What is this?

Controls which ports the outside world can reach. The firewall denies incoming connections by default, so a service is unreachable until you open its port here — that is what keeps a fresh install from being wide open the moment it gets an address. Open only what you actually need: a Minecraft server wants 25565/tcp, and nothing else needs to be open for it to work.

Careful with SSH. If you are connected over SSH and you turn the firewall on without 22/tcp allowed, you will lose the connection and need physical access to get back in.

Remote Access

What is this?

How you reach this panel from somewhere that isn't this machine. It rides a private encrypted network (Tailscale), so the control panel is never exposed to the open internet — there is no public address to find and nothing to port-forward.

The panel will only listen on loopback (this machine alone) or on a tunnel address. A LAN or public address is refused outright, because the panel speaks plain HTTP and your password would cross the wire in the clear.

Secure Terminal

guarded
How does the terminal work?

A normal shell — type a command and press Enter; output appears above. It runs in your home folder as you. Destructive commands (like rm -rf, dd, mkfs) are intercepted and need you to type CONFIRM first, so you can't wipe the machine by accident. Use sudo for admin tasks; pacman for packages (or just use the Apps page).

SSH keys

What is this?

Public keys that may log into this server over SSH. A key here is a login — anyone holding the matching private key gets in, with no password. Keys are far safer than passwords for a server, because there is nothing guessable to brute-force.

Paste the contents of your .pub file (usually ~/.ssh/id_ed25519.pub). Never paste a private key — that is the half that stays on your own machine, and pasting it here would be handing it away.

Boot & Recovery

Hotswap sets the next boot to another installed OS (or opens the boot menu). The installer can set up or remove Outlaw Server — your other OS and data stay untouched unless you explicitly choose to wipe.

Report a problem

If something failed, crashed, or bounced you to the session picker, collect the log and report it. It gathers errors + warnings from the desktop, the dev session, Xorg and the system journal — deduplicated, no repeats. Copy the log, click Open GitHub issues, and paste it into a new issue. When you’re done reporting, Clear it so already-sent errors don’t pile up with new ones.
